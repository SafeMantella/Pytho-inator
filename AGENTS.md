# Pytho-inator

After a response that did repeatable work, every agent, including Claude Code, runs `./pytho-inator glance` on the files it created or edited. Empty stdout: say nothing. A hit: one local Python CLI, at most three lines, and ask before building.

The procedure is `skills/pytho-inator/SKILL.md` (Portuguese). Build rules: `skills/pytho-inator/references/gates.md`. Human docs: `README.md` and `README.pt-BR.md`.

Do not install a paid API, and do not run what you just wrote, until the user says yes. `i-have-adhd`, `ponytail`, and `superpowers` are optional and work much better together. `./pytho-inator companions` only warns and prints the repo links. Keep going. When building a CLI, read the ponytail skill and set intensity to ultra before the first line (`/ponytail ultra` on Claude Code). The ladder in `gates.md` is the fallback when ponytail is missing.
