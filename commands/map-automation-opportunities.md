# `/map-automation-opportunities`

Arquivo da tarefa: a skill `pytho-inator` (`ferramentas/Pytho-inator/skills/pytho-inator/SKILL.md`). Seguir a seção `/map-automation-opportunities` de lá, nesta ordem:

1. `ferramentas/Pytho-inator/pytho-inator map` com a raiz em `$ARGUMENTS` (vazio = o diretório atual). Não ler as skills inteiras. A saída do CLI é o mapa.
2. Ler `ferramentas/Pytho-inator/skills/pytho-inator/references/cli-contract.md`.
3. Mostrar no máximo 5. Preferir `shape=chain`. Descartar `fan-out` que é menu e qualquer passo que seja julgamento.
4. Parar. Não construir neste comando, a menos que o Pedro já tenha pedido a construção na mesma mensagem. Construção segue a seção "Construir" da skill.
