# `/check-skills`

Arquivo da tarefa: a skill `pytho-inator` (`ferramentas/Pytho-inator/skills/pytho-inator/SKILL.md`). Seguir a seção `/check-skills` de lá, nesta ordem:

1. `ferramentas/Pytho-inator/pytho-inator check` com a raiz em `$ARGUMENTS` (vazio = o diretório atual). Não ler as skills inteiras.
2. Ler `ferramentas/Pytho-inator/skills/pytho-inator/references/cli-contract.md`.
3. Para cada hit: qual trecho vira um comando só, e o que permanece na skill quando `judgment=keep`.
4. Parar. Não editar skill nem script até o Pedro escolher. A construção segue a seção "Construir" da skill.
